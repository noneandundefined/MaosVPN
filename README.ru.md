# Maos VPN — руководство пользователя

[English version](README.en.md) · [Главная страница](README.md) · [Скачать последнюю версию](../../releases/latest)

Maos VPN — простой open-source клиент подписок для Intel‑Mac с macOS Catalina 10.15 и новее. Клиент создаёт системный TUN-интерфейс, поэтому через выбранный VPN-сервер проходит трафик браузеров и приложений.

Приложение проверяет GitHub Releases при запуске. Когда доступна новая версия, Maos VPN может скачать её, проверить контрольную сумму, установить и перезапуститься без открытия браузера. Проверку также можно запустить через меню **Maos VPN → Проверить обновления…**.

## Установка

1. Откройте **[GitHub Releases](../../releases/latest)**.
2. Скачайте `MaosVPN-macOS-10.15-Intel.dmg`.
3. Откройте DMG и перетащите **Maos VPN.app** в папку **Программы**.
4. Нажмите приложение правой кнопкой → **Открыть** → подтвердите **Открыть**.

Дополнительное подтверждение требуется потому, что публичная сборка подписана ad-hoc. В будущем подпись Apple Developer ID сможет убрать этот шаг.

Если macOS не показывает кнопку **Открыть**, один раз выполните в Терминале:

```bash
xattr -dr com.apple.quarantine "/Applications/Maos VPN.app"
```

Выполняйте эту команду только для приложения, скачанного с официальной страницы Releases этого проекта. По возможности сверяйте SHA-256 с файлом `SHA256SUMS.txt`.

## Подключение

1. Запустите Maos VPN.
2. Выберите **Русский** или **English** в правом верхнем углу.
3. Вставьте первую HTTPS-ссылку и нажмите **Добавить подписку**.
4. Через кнопку **Добавить подписку** на верхней панели можно добавить другие подписки с именами или конфигурации sing-box JSON.
5. Раскройте нужную группу и выберите сервер слева.
6. Используйте поиск, **Тест пинга** или **Автовыбор**, затем нажмите большую круглую кнопку подключения. Во время работы внутри неё отображается длительность сеанса.
7. Один раз введите пароль администратора macOS при установке служебного VPN-helper.

Пароль используется macOS для установки служебного VPN-helper. Maos VPN не получает и не сохраняет его; обычные подключения и отключения больше не запрашивают пароль.

## Поддерживаемые форматы

- Подписки Base64, обычным текстом или в формате sing-box JSON;
- VLESS;
- VMess;
- Trojan;
- Shadowsocks;
- Hysteria2, включая обфускацию Salamander;
- TCP, HTTP, WebSocket, gRPC, HTTPUpgrade, QUIC, TLS и Reality — если параметры присутствуют в ссылке профиля.

Не все провайдеры используют стандартные share-ссылки. Если профиль пропускается, создайте Bug Report, предварительно удалив адреса, UUID, пароли, public key и токен подписки.

Источники подписок и их группы серверов сохраняются локально. Сохранённые ссылки больше не отображаются в главном окне.

## Удаление

1. Отключите VPN.
2. Завершите Maos VPN.
3. Переместите приложение из папки **Программы** в Корзину.
4. При необходимости удалите локальные настройки:

```bash
rm -rf "$HOME/Library/Application Support/MaosVPN"
defaults delete app.maosvpn.client
```

Последний шаг удаляет сохранённые профили и настройки.

## Для разработчиков

Проект собирается через Swift Package Manager и AppKit. В релиз включается официальная legacy-сборка `sing-box` для Intel. См. [архитектуру](docs/ARCHITECTURE.md) и [инструкцию для участников](CONTRIBUTING.ru.md).


### Новое в версии 1.2.0

- **Автовыбор** находится первым в списке серверов: режим sing-box URLTest тестирует доступность маршрутов каждые 30 секунд и меняет сервер для новых соединений без отключения TUN.
- **Обновление подписки:** нажмите **↻** возле её названия, чтобы загрузить свежий список серверов по сохранённой ссылке. Повторно добавлять подписку не нужно.
- **Удаление подписки:** нажмите **×** возле её названия и подтвердите удаление из приложения.
- Кнопка **«Проверить пинг серверов»** всегда находится над списком, а левая панель стала шире.

Управление подписками доступно при отключённом VPN. Режим автовыбора не прерывает уже открытые соединения; новый сервер применяется к новым соединениям. Для импортированного JSON без URL автоматическое обновление невозможно.


### Новое в версии 1.2.1

- Нажмите **ⓘ** рядом с названием подписки: откроются срок действия, использованный трафик, сайт провайдера, ссылка на поддержку и скрытая по умолчанию ссылка подписки (кнопки «Показать» и «Скопировать ссылку»).
- Данные приходят из заголовков HTTP `subscription-userinfo`, `profile-web-page-url`, `support-url`, `profile-title` или аналогичных строк `#...` в самой подписке. Если провайдер их не передаёт, неизвестные значения не придумываются.
- После установки обновления нажмите **↻**, чтобы получить метаданные для ранее добавленных подписок.
- **Проверить пинг**, **обновить** и **удалить подписку** теперь можно при подключённом VPN. Список обновляется без обрыва туннеля. Изменения маршрутов вступают в силу после следующего подключения. Удаление последней подписки отключает VPN с предупреждением.


### Новое в версии 1.2.2: сравнение User-Agent

При добавлении и ручном обновлении **URL-подписки** MaosVPN последовательно запрашивает её с четырьмя User-Agent: `Karing`, `Happ/3.3.6`, `v2rayNG/2.2.6`, `sing-box/1.13.14`. Приложение выбирает **тот ответ, где больше всего серверов, которые оно может импортировать**, не объединяя различные форматы между собой. В окне **ⓘ** видны выбранный формат и количество совместимых серверов в каждом успешном ответе.

Число серверов может по-прежнему отличаться от Happ: например, **Hysteria v1** пока не поддерживается MaosVPN. Проверка ограничена четырьмя последовательными запросами; при HTTP 401/403/429 или блокировке HWID дальнейшие запросы не выполняются. В случае нестабильной сети сохраняется последний успешный вариант текущего обновления. Установленные подписки и устройства не пересоздаются. Для проверки своего провайдера нажмите **↻** в приложении; не публикуйте приватную ссылку подписки.


### Новое в Maos VPN v1.3.0

- **Hysteria v1**: импорт и подключение к серверам этого протокола, отдельно от Hysteria2.
- **JSON sing-box**: сохранение специальных параметров транспорта/TLS и поддержка зависимых серверов через `detour` (включая SOCKS и другие допустимые промежуточные outbounds). В режиме «Автовыбор» для цепочек используются уникальные имена.
- **Диагностика импорта**: в карточке подписки (**ⓘ**) показываются «получено / импортировано / пропущено», формат User-Agent и причины пропуска. Неподдерживаемые записи не скрываются от пользователя без объяснения.
- **Разные User-Agent**: сохранён безопасный последовательный опрос Karing, Happ, v2rayNG и sing-box. Из сравниваемых ответов выбирается один с максимальным количеством поддерживаемых узлов. При отказе в доступе, лимите устройства или HTTP 429 проверка прекращается.
- Чтобы проверить текущую подписку после обновления приложения, нажмите **↻**, затем **ⓘ**.

Примечание: не все протоколы Happ могут быть поддержаны одновременно. Отчёт показывает, какие ещё не удалось импортировать и по какой причине. URL подписки и секретные данные не записываются в отчёт.
