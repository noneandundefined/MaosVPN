# Maos VPN — руководство пользователя

[English version](README.en.md) · [Главная страница](README.md) · [Скачать последнюю версию](../../releases/latest)

Maos VPN — простой open-source клиент подписок для Intel‑Mac с macOS Catalina 10.15 и новее. Клиент создаёт системный TUN-интерфейс, поэтому через выбранный VPN-сервер проходит трафик браузеров и приложений.

Приложение проверяет GitHub Releases при запуске. Когда доступна новая версия, Maos VPN может скачать её, проверить контрольную сумму, установить и перезапуститься без открытия браузера. Проверку также можно запустить через меню **Maos VPN → Проверить обновления…**.

## Установка

1. Откройте **[GitHub Releases](../../releases/latest)**.
2. Скачайте `MaosVPN-macOS-10.15-Intel.dmg`.
3. Откройте DMG и перетащите **Maos VPN.app** в папку **Программы**.
4. Нажмите приложение правой кнопкой → **Открыть** → подтвердите **Открыть**.

Дополнительное подтверждение требуется потому, что публичная сборка подписана ad-hoc. В будущем подпись Apple Developer ID сможет убрать этот шаг.

Если macOS не показывает кнопку **Открыть**, один раз выполните в Терминале:

```bash
xattr -dr com.apple.quarantine "/Applications/Maos VPN.app"
```

Выполняйте эту команду только для приложения, скачанного с официальной страницы Releases этого проекта. По возможности сверяйте SHA-256 с файлом `SHA256SUMS.txt`.

## Подключение

1. Запустите Maos VPN.
2. Выберите **Русский** или **English** в правом верхнем углу.
3. Вставьте HTTPS-ссылку подписки.
4. Нажмите **Загрузить** и выберите сервер слева.
5. Нажмите **Подключиться**.
6. Введите пароль администратора macOS, когда его запросит система.

Пароль используется macOS для создания TUN-интерфейса. Maos VPN не получает и не сохраняет его.

## Поддерживаемые форматы

- Подписки Base64 или обычным текстом;
- VLESS;
- VMess;
- Trojan;
- Shadowsocks;
- TCP, HTTP, WebSocket, gRPC, HTTPUpgrade, QUIC, TLS и Reality — если параметры присутствуют в ссылке профиля.

Не все провайдеры используют стандартные share-ссылки. Если профиль пропускается, создайте Bug Report, предварительно удалив адреса, UUID, пароли, public key и токен подписки.

## Обновление серверов

Вставьте прежнюю ссылку подписки и снова нажмите **Загрузить**. Локальный список будет заменён актуальными корректными профилями от провайдера.

## Удаление

1. Отключите VPN.
2. Завершите Maos VPN.
3. Переместите приложение из папки **Программы** в Корзину.
4. При необходимости удалите локальные настройки:

```bash
rm -rf "$HOME/Library/Application Support/MaosVPN"
defaults delete app.maosvpn.client
```

Последний шаг удаляет сохранённые профили и настройки.

Проект собирается через Swift Package Manager и AppKit. В релиз включается официальная legacy-сборка `sing-box` для Intel. См. [архитектуру](docs/ARCHITECTURE.md) и [инструкцию для участников](CONTRIBUTING.ru.md).
