# Конфиденциальность

Maos VPN не содержит аналитики, рекламы, телеметрии, SDK отчётов о сбоях и собственного серверного backend.

## Локальные данные

В настройках текущего пользователя macOS сохраняются язык интерфейса, добавленные ссылки подписок или JSON-источники, разобранные профили, идентификатор последнего VPN-процесса и случайный идентификатор установки. Источники скрыты в главном интерфейсе, но остаются сохранёнными локально. Идентификатор установки остаётся постоянным, чтобы провайдеры с ограничением устройств не считали каждое обновление подписки новым устройством. Он не создаётся из серийного номера Mac, Apple ID, имени пользователя или других аппаратных идентификаторов. Конфигурация `sing-box` находится в:

```text
~/Library/Application Support/MaosVPN/config.json
```

Файл создаётся с правами только для пользователя. Во время работы движка временный журнал может находиться в `/tmp`.

Ссылка подписки и профили могут содержать credentials. Пользователь или программа с доступом к вашей учётной записи macOS либо незашифрованной резервной копии потенциально может прочитать эти настройки. Защищайте учётную запись и отзывайте раскрытые подписки у провайдера.

## Сетевые соединения

Приложение обращается только к:

- ссылке подписки, введённой пользователем;
- серверам из этой подписки;
- DNS-сервисам, используемым для работы VPN.
- публичному API GitHub Releases и адресам загрузки релизов для проверки и установки обновлений.

При загрузке подписки Maos VPN передаёт случайный идентификатор установки в заголовке `X-Hwid`, а также название и версию операционной системы и общее название модели `Mac`. Это необходимо для совместимости с панелями подписок формата Happ. Данные отправляются только по введённой пользователем ссылке подписки и не передаются проекту Maos VPN.

При автоматической проверке GitHub получает версию приложения и общий User-Agent Maos VPN. Ссылки подписок, профили, идентификатор установки и VPN-трафик не передаются. Проверка выполняется при запуске, затем каждые шесть часов работы; ручную проверку можно запустить из меню приложения.

## Пароль администратора

Окно пароля показывает и обрабатывает macOS при первой установке или обновлении служебного VPN-helper. Maos VPN получает только результат операции и никогда не получает и не сохраняет пароль. Обычное подключение и отключение используют установленную службу и повторно пароль не запрашивают.

Инструкция полного удаления находится в [README.ru.md](../README.ru.md).
