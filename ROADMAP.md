# Roadmap

This roadmap describes direction, not guaranteed delivery dates.

## Near term

- Validate the first public Intel/Catalina release on physical Macs.
- Improve connection health and error reporting.
- Add safe, redacted diagnostic export.
- Expand parser fixtures for real-world standard share links.
- Add optional Developer ID signing and notarization support.

## Later

- Subscription refresh scheduling.
- Latency checks without exposing profile credentials.
- Additional standard protocols when supported by the bundled engine.
- Apple Silicon universal release if community demand exists.

Provider-specific formats, analytics, advertising, and closed tracking SDKs are outside the current project scope.
