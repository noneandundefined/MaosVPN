# Как помочь Maos VPN

[English version](CONTRIBUTING.md)

Мы принимаем исправления ошибок, отчёты о совместимости, переводы, улучшения документации и конкретные предложения функций.

## Перед созданием Issue

- Найдите похожую проблему и прочитайте [руководство поддержки](SUPPORT.md).
- По возможности проверьте последнюю версию.
- Удалите ссылки подписок, UUID, пароли, адреса серверов, Reality-ключи и данные аккаунта провайдера.
- Не прикладывайте полный журнал, пока не проверите и не скроете секретные данные.

Уязвимости сообщаются по правилам [SECURITY.md](SECURITY.md), а не через публичный Issue.

## Среда разработки

Нужен Mac с Xcode Command Line Tools. Релиз собирается для Intel macOS 10.15 и включает официальную legacy-сборку `sing-box`.

```bash
swift test
swift build
```

Локальная упаковка Intel-приложения:

```bash
APP_VERSION=0.1.0 BUILD_NUMBER=1 \
  bash Scripts/package.sh /path/to/sing-box /path/to/sing-box-LICENSE
```

## Pull Request

1. Создайте отдельную ветку от основной.
2. Не смешивайте изменение с посторонним форматированием и рефакторингом.
3. Добавьте или обновите тесты парсера и конфигурации.
4. Обновите английские и русские пользовательские тексты.
5. Запустите `swift test`; для конфигурации также проверьте `sing-box check`.
6. Опишите влияние на пользователя, совместимость и ручную проверку.

Нельзя добавлять аналитику, рекламу, секреты провайдера или исполняемые файлы в историю Git.

## Стиль кода

- Используйте AppKit API, доступные в macOS 10.15.
- Сетевую логику и разбор профилей размещайте в `MaosVPNCore`.
- Привилегированные операции должны быть минимальными и понятными.
- Никогда не записывайте credentials и полные share-ссылки в журнал.
- Не добавляйте ненужные внешние зависимости.
- Поддерживайте одинаковое содержание русского и английского интерфейса.

Отправляя изменение, вы соглашаетесь опубликовать его под MIT License проекта.
